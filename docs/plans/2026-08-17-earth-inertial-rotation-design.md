# 地球惯性参考系自转设计

## 目标

让地球实体相对固定星空真实自转，而不是继续用“静止地球 + 旋转太阳方向”模拟昼夜。默认轨道相机保持惯性，大陆会从镜头下经过；暂停、倒放和倍速均由统一模拟 UTC 驱动。

## 坐标与光照

- 地球局部坐标保持现有 NASA 等距圆柱贴图的经纬度方向。
- 内层地球表面按 Greenwich sidereal time 绕局部北极轴旋转。
- 外层按 J2000 平均黄赤交角 `23.4392911°` 倾斜，使自转轴落在现有日心黄道场景中。
- 太阳方向由当前地固方向施加同一组“自转 + 轴倾角”变换得到惯性方向。这样每个地理点的太阳高度与现有 Astronomy Engine 结果一致，同时避免昼夜线被计算两次。
- 星空、月球轨道和相机不随地球旋转。

## 连续动画

React 的模拟时间每 100 ms 更新一次。地球渲染帧复用小天体已有的 `frameSimulationUtcMs` 在两个状态更新之间插值，避免高倍速下每 100 ms 跳一次。暂停时直接使用状态 UTC，不产生漂移；负倍率自然反向。

## 验证

- 纯函数测试固定 J2000 恒星时、轴倾角和一恒星日周期。
- 数学回归验证变换前后的地理点太阳入射点积相等，防止双重旋转。
- 场景边界测试确认 Earth 表面使用逐帧 UTC、实体旋转组和惯性太阳方向。
- 全量单测、生产构建和本地浏览器检查覆盖暂停及高倍速画面。
