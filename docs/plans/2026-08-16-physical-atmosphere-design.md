# 物理大气层设计

## 目标

把当前均匀发光的地球描边替换为偏真实轨道摄影风格：日照侧只有薄蓝散射层，夜侧快速衰减，晨昏线仅保留很窄的暖色，不改变 NASA 地表影像、太阳、导航或数据逻辑。

## 根因

现有 shader 在放大 4% 的球面上使用 `pow(1 - abs(normal · view), 2.35)` 直接生成轮廓光。这个公式不计算视线穿过大气球壳的距离，也不考虑随高度下降的气体密度，因此会形成厚度固定、亮暗两侧近似对称的霓虹圆环。

## 渲染方案

使用深度测试开启的三维球壳，而不是始终面向相机的二维环带。相机射线分别与地表球和大气外壳求交，只积分地表之外的可见路径，因此近距离和斜视角下大气仍位于地球外部，不会穿进表面。球壳内按高度指数衰减密度，桌面每像素采样 3 次、移动端采样 2 次，累积近似光学厚度；Rayleigh 蓝光由太阳高度控制，Mie 前向散射保持很弱，暖色只出现在太阳高度接近地平线的窄区间。

## 验收

- shader 包含射线/球体求交、指数密度采样和光学厚度积分。
- 大气使用真实三维球壳与深度遮挡，不使用 Billboard 或关闭深度测试的环带。
- 不再以 `abs(dot(normal, view))` 作为大气主轮廓来源。
- 默认轨道下夜侧不形成完整亮圈，日照侧是薄蓝边，晨昏暖色不发紫。
- 全量测试与生产构建通过，桌面目标保持 60 fps。
