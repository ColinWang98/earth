# 手动卫星影像更新设计

## 目标

页面首屏不再自动探测和下载 NASA GIBS 的 4K/8K 影像。项目随站点发布一张覆盖完整的 NASA VIIRS 4K 真彩快照，浏览器优先预加载它；用户点击“更新卫星影像”时，才请求更新的 NASA 近实时真彩影像。Blue Marble 只用于补齐极区无观测像素，不再作为首屏主贴图。

## 数据流

`App` 保存一次显式影像请求，其中包含递增编号和点击时的当前 UTC 时间。没有请求时，`Scene` 的影像 hook 返回预存 NASA 快照，不访问 GIBS。点击按钮后，hook 沿用现有覆盖率探测、8K 降级和纹理释放逻辑。加载过程中按钮禁用并显示“正在更新…”，成功后显示最新观测日期和来源；失败时保留预存 NASA 快照并明确标记回退。时间播放或日期变化不会自动触发网络请求，必须再次点击按钮。

`index.html` 使用 `preload` 提前请求 `earth-nasa-viirs-2026-08-15-4k.jpg`。状态栏始终标明这张预存图的观测日期，不把它描述成实时影像。该资源由 GitHub Pages 正常缓存，不新增 Service Worker。

## 中国公开数据研究

国家卫星气象中心提供免费的风云 WMS，能力文档声明无费用、无访问限制，并允许跨域访问。`FY3F_MERSI` 提供每日全球影像，但实际测试发现全球单图请求可能返回空白，区域请求有效；可靠接入需要分块下载、覆盖率检测和浏览器拼接。`GEOS_IRX` 是每小时红外拼图，不是真彩色。本阶段仅记录该来源，不把它加入运行时，以免降低首版稳定性。

## 验收

- 初始渲染不执行 NASA 覆盖率探测或 GIBS 下载。
- 预存 NASA VIIRS 4K 快照被 HTML 预加载并作为主贴图。
- 点击按钮只触发一次当前日期请求，加载中不可重复点击。
- 时间变化不会自行更新影像；再次点击可重新请求。
- NASA 失败后保留预存快照，原有 GPU 纹理释放逻辑继续工作。
